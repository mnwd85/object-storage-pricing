## 雨云 ROS 的计费规则：只算存储和上行流量

ROS（Rain Object Storage）兼容 S3 协议，原来用 s3cmd、rclone、PicGo、Chevereto 这些工具和程序的，把 endpoint 和密钥换掉基本就能接上，不用改代码。

计费按套餐包月走，只算两项：存储容量、上行流量（雨云向你发送文件，也就是你下载的量）。上传不计费，没有请求费，也没有归档取回那类费用。云服务器和对象存储在同一个区域、走内网地址访问时，上下行流量都不计入套餐。

这一点对建站的人影响最大。网站程序跑在雨云云服务器上，图片走内网拉到页面里，这部分流量完全不消耗套餐额度。

套餐分三种形态：

- **平衡套餐**：存储和流量配额相等，图床、小型网站静态资源这类既存又取的场景
- **存储优先**：存储大、流量小，备份归档、高清素材囤积
- **流量优先**：存储小、流量大，软件更新包、音视频分发

## 同样 1TB 数据放一个月，流量费差多少

存储单价是最容易看的部分，也最不决定总账。

AWS S3 标准存储约 $0.023/GB/月，出站流量 $0.09/GB。1TB 出站大约 90 美元（按相关文章换算约 650 元人民币），而 1TB 数据存一个月只要二十几美元。存进去便宜，取出来贵，比例差了三倍以上。

阿里云 OSS 的外网流出按阶梯分时段：闲时 00:00–08:00 是 0.25 元/GB，忙时 08:00–24:00 是 0.50 元/GB，CDN 回源 0.15 元/GB。流入流量免费，同地域内网流出也免费。1TB 全走忙时外网，就是 512 元流量费。存储按量标准型本地冗余 0.09 元/GB/月，1TB 约 92 元。两块加起来，一个月六百元上下，这里面还没算 API 请求费。

雨云那套 1TB + 1TB 的平衡套餐是 198 元/月，流量已经包在里面。

不过公有云也不是在所有规模上都吃亏。阿里云双十一期间 500GB 标准本地冗余存储包 118.99 元/年，新老同享、续费同价，折下来约 9.9 元/月，同城冗余版本 171.99 元/年起。这个价格买纯存储部分，比绝大多数按量方案都低。

判断标准很简单：把上个月的下载量（不是上传量）翻出来，和存储量比一下。下载量不到存储量十分之一的，买存储优先；两者接近的，买平衡；下载量是存储量好几倍的，买流量优先。

## 存储类型怎么选，最短存储时长会额外收费

公有云把存储拆成标准、低频、归档、深度归档几档，单价依次下降，代价是取回速度和最短存储时长。

阿里云的最短存储时长：低频 30 天、归档 60 天、冷归档与深度冷归档 180 天。腾讯云 COS 是低频 30 天、归档 90 天、深度归档 180 天。华为云 OBS 分标准、低频、归档、深度归档四类，归档解冻通常 1 到 5 分钟，深度归档 12 到 48 小时。

**“最短存储时长”的意思是：存进去没到天数就删，仍按整个周期计费。** 一份 100GB 的文件放进低频存一天就删，按 30 天收钱，比放标准存储一个月还贵。这条规则不写在价格表里，写在计费文档里。

按访问频率选类型的经验分界，华为云给的版本是 30 天内热数据用标准、30 到 90 天用低频、90 天以上用归档；腾讯云的口径是月均访问 1 到 2 次用低频、一年未必取一次用归档。落到具体场景：

| 场景 | 建议类型 |
| --- | --- |
| 网站图片、用户上传文件 | 标准 |
| 数据库自动备份 | 低频或归档 |
| 近 3 个月业务日志 | 低频 |
| 3 个月前日志、历史交易记录 | 归档 / 深度归档 |

真正省钱的动作是让生命周期规则自动完成类型转换，而不是手动判断。阿里云的示例规则是 30 天未访问转低频、90 天转归档、一年后删除，用 ossutil 一条命令挂上去。华为云日志场景用的也是 30/90/365 天这套节奏。

雨云 ROS 走的是另一条路：套餐制，存储和流量定额，没有存储类型分层，也就没有类型切换和提前删除补费这一层规则，只算存储和上行流量两项。对不想研究生命周期配置的人，这省掉了一整块心智负担；对本来就该把三年前的日志压进深度归档的人，公有云的分层定价仍然更省。

## 谁适合买，谁别买

**适合的：**

图床、相册、博客静态资源，流量和存储大体同步增长，平衡套餐对得上。软件包、音频工程、素材分发，流量远大于存储，宁波的流量优先档 200GB + 1TB 只要 100 元。数据库冷备、虚拟机镜像、摄影原始素材这类存进去就不动的，十堰存储优先 1TB 只要 99 元，比多数网盘便宜，还能用 rclone 挂载。

已经在用 s3cmd、rclone、PicGo、Chevereto 的人，迁移成本接近零，改个配置就完事。

云服务器也在雨云上的，静态资源走内网，流量双重免费，这部分账很容易算。

**不适合的：**

需要多地域容灾、跨区域复制的，单节点套餐满足不了。需要归档、深度归档分级定价来压冷数据成本的，套餐制给不了这个粒度。业务流量波动大又承担不起掉线的，得先把弹性计费开关打开并盯着余量，否则超量即停。需要向量桶、表格桶这类面向 AI 和数据湖的存储形态的，也不在这个产品范围内。

1. **算下载量，不是上传量。** 从旧账单或 CDN 后台拉一个月的出流量，和存储量对比，决定买哪种形态。
